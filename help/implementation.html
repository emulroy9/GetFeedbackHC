Installing and Implementing GetFeedback on Your Site

To start collecting feedback, you need to install the GetFeedback Digital JavaScript snippet. This snippet acts as a "container" code—once it is on your site, you can launch, edit, or disable surveys and feedback buttons directly from your dashboard without ever having to touch your website's code again.

Implementation Steps

To access your unique installation code:

  1. In either the Feedback Button or Trigger-based form section, navigate to the Setup tab in the left sidebar.
  2. Select Installation.
  3. You will see your unique JavaScript snippet. Click Copy code.
  4. Note that for Embedded forms the code is found in the Install section.

Option 1: Manual Installation (Directly in HTML)

If you have direct access to your website's source code, follow these steps:

  1. Open your website's global header template or master page.
  2. Paste the copied snippet into the <body> section.
  3. Placement Tip: For the best performance, place the code right before the </body>. For Embedded forms you will also need to place your widget code at any point of the page where you want the widget to appear.

Option 2: Installation via Google Tag Manager (GTM)

If your team uses GTM to manage third-party scripts, you can deploy GetFeedback across your entire site in a few clicks. This is the recommended method for marketing teams who do not have daily access to developers.

Step 1: Create a New Tag

  1. Log into your Google Tag Manager account and select the correct Container.
  2. Click Add a new tag.
  3. Name your tag (e.g., "GetFeedback Digital - Main Snippet").

Step 2: Configure the Tag

  1. Click on Tag Configuration and select Custom HTML from the list of tag types.
  2. In the HTML text box, paste the code snippet you copied from the GetFeedback Installation page.
  3. Ensure "Support document.write" is unchecked.

Step 3: Set the Trigger

  1. Click on Triggering.
  2. Select All Pages (Page View). This ensures that your feedback buttons and Trigger-based forms can appear anywhere on your site.

Step 4: Save and Publish

  1. Click Save in the top right corner.
  2. Click Submit and then Publish to push the code live to your website.

Technical Note: Single Page Applications (SPA)

Modern websites built on frameworks like React, Angular, or Vue do not perform traditional "full page refreshes" when a user navigates between views. For Trigger-based forms, our code snippet checks targeting rules (like URL matches) on the initial page load, you must simulate a page refresh when a "virtual" page change occurs.

The virtual_pageview Command

Add the following JavaScript call to your application's router or navigation logic:

window.usabilla_live('virtual_pageview');

Why this is necessary

  • Refreshes Targeting: It tells the script to re-check if a Trigger-based form should show on the new URL.
  • Data Accuracy: It ensures your analytics and behavioural triggers (like Time on Page) reset correctly for the new view.
  • Implementation: This should be triggered every time the URL path changes within your application.

Verifying the Installation

Once the code is installed (either manually or via GTM):

  1. Visit your website and open the browser's developer console (F12).
  2. Type usabilla_live and press Enter. If the installation was successful, the console will return a function.
  3. Navigate to the Review tab in your GetFeedback builder to confirm that the platform is successfully receiving data from your site.
Next Step: Once your code is installed, move to the Feedback Button, Trigger-based Forms, or Embedded Forms article to define who should see your surveys.

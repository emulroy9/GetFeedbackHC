Setting Up and Using Custom Variables

Custom Variables allow you to enrich your feedback with metadata from your own systems—such as a user's Account ID, Subscription Plan, or a specific Session ID. This data is captured alongside the user's feedback, allowing you to filter your results in the Insights dashboard or set advanced targeting rules.

Step 1: Adding a Variable

To begin, you must define which data points GetFeedback should listen for.

  1. In the campaign builder, go to the Setup tab and select Targeting.
  2. Scroll down to the Variables section and click Add variable.

Step 2: Defining the Source

When you add a variable, you must tell GetFeedback where to find the data on your website.

  1. Variable Name: Enter an internal name for this data (e.g., "User Type").
  2. Source: Choose one of the following three sources:
    • JavaScript Variable: Pulls a value from a global variable in your site's code (e.g., window.user_tier).
    • Cookie: Pulls data from a cookie stored in the user's browser (e.g., auth_token).
    • Query Parameter: Pulls data directly from the URL (e.g., ?source=newsletter).
  3. Source Name: Enter the exact name of the variable, cookie, or parameter as it appears in your code.

Step 3: Using Variables for Targeting

Once a variable is defined, you can use it to control which audience segments see your survey.

  1. Toggle on Show survey based on custom variable.
  2. Select your variable from the list.
  3. Set your logic (e.g., "Show survey if Subscription Plan is equal to Premium").
  4. You can combine multiple variables using AND/OR logic to create highly specific audience groups.

Step 4: Insights and Reporting

The real power of Custom Variables comes after you've collected feedback. When you visit your Insights dashboard:

  • Response Metadata: Every response will show the captured variable values.
  • Filtering: You can filter your entire dashboard by these variables. For example, "Show me only the NPS scores for users with a 'Cart Value' over $100."
  • Exports: These variables are included in all CSV and Excel exports for further analysis in tools like Excel or Tableau. Learn more in How to Analyse Your Results.

Technical Pro-Tips

  • Data Types: Ensure you select the correct data type (String, Number, or Boolean) in the setup screen to ensure your filters work correctly in reporting.
  • Privacy: Never capture Personally Identifiable Information (PII) like passwords or credit card numbers as custom variables.
  • Testing: Before launching, use the browser console on your live site to verify that the variable you are targeting actually contains the expected value.

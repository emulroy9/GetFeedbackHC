Setting Up Embedded Forms (In-Page)

Embedded forms allow you to collect feedback directly within your website content, such as at the end of help articles or documentation pages. Unlike floating buttons or pop-ups, these forms are built seamlessly into your page layout.

Step 1: Start Your Form

  1. From the Home dashboard, navigate to Embedded Feedback and click Create.
  2. Select Form Type: Choose how your feedback experience begins. This "Start Form" remains static on your page:
    • Mood: A quick emoji-based rating.
    • NPS: The standard Net Promoter Score scale.
    • Toggle: A simple "Yes/No" interaction (e.g., "Was this helpful?").

Step 2: Build the Experience

The builder uses a multi-page structure, allowing you to create a conversation with your users.

The Start Page

This is the form your users see first. Customize the Title (e.g., "Was this useful for you?") and define the initial interaction.

Form Pages (Follow-up Questions)

You can add follow-up questions that appear after a user interacts with the initial form.

  • Logical Flow: If a user clicks "No" on a Toggle form, you can automatically show a Form Page asking "What can we do to improve this?"
  • Question Types: Add Input Text, Text Areas, Checkboxes, Radio Buttons, or additional Ratings from the sidebar.
  • Clear All: Use the "Clear All" button in the top right if you need to reset the page design.

The End Page

Configure the final screen users see after submitting their feedback. Customize the Header (e.g., "Thank You") and the confirmation message.

Step 3: Install Your Form

Unlike floating buttons, Embedded forms require a two-step installation to ensure the form appears in the correct location.

1. The Global Script Snippet

Click View Code for the Script Snippet. Copy and paste this code into your website's HTML, specifically just before the closing </body> tag on every page where you want forms to function.

2. The Form Placement Code

This specific "nonce" or identifier tells the global script exactly where to render the form on a specific page.

  • Placement: Copy the Form Code and paste it into the specific <div> or section of your HTML where the form should be displayed.
  • Custom Variables (Advanced): Check the Configure custom variables box to add metadata to your feedback. You can define up to three optional variables (Category, Subcategory, Item) to help group and filter responses in your feedback dashboard. Learn more in our Custom Variables guide.

Pro-Tip: Preview Your Design

Before finishing, click the Preview button at the top of the builder. This allows you to test the interactive flow—such as clicking the "Toggle" buttons—to ensure your follow-up questions appear exactly as intended within the embedded container.

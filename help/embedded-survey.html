Setting Up an Embedded Form

An Embedded Form lets you collect feedback directly within your website content (for example, at the end of help articles or documentation pages). Unlike the Feedback Button or Trigger-based Forms, an Embedded Form is placed directly into your page HTML and renders inline with your content.

Step 1: Start Your Form

  1. To begin, from any section of the dashboard, click the Create button on the right hand side of the page header. An overlay wizard modal titled "How should feedback appear?" will pop up on your screen. Select the Embedded form selection option asset from here, and click Continue to advance straight into your workspace framework builder.
  2. Note the Add questions menu on the left — it lists all the question types available in the builder. Use this menu to add controls to any page.
  3. You can also toggle Store IP Address and Store User Location from the Advanced Settings menu.

Step 2: Build the Experience

The builder uses a multi-page structure, allowing you to create a conversation with your users. Once you open the Build form view, you can add your chosen questions from the previously mentioned menu on the left.

Use the page tabs at the top of the builder to configure the Start page, any intermediary pages, and the End page. You can preview the form using the Preview button, and when you click Next you'll be shown the Install page where you can copy the global script and widget code.

The Start Page

This is the form your users see first. Customize the Title (e.g., "Was this useful for you?") and define the initial interaction.

  • Single question only: The Start page accepts only one control — choose between NPS, Mood, or a Toggle/Choice interaction.

Adding Pages

You can add follow-up questions to new pages that will appear after your start page.

These additional pages allow for a variety of question types, and multiple questions per page.

You can give these pages their own titles, and add any of the following question types from the Add questions menu:

  • Feedback: NPS, Rating, Mood
  • Input: Input text, Text area, Email
  • Choice: Dropdown, Checkbox, Radio buttons, Toggle
  • Format: Header, Paragraph

The End Page

Configure the final screen users see after submitting their feedback. Customize the Header (e.g., "Thank You") and the confirmation message.

Common End page elements

The End page typically contains confirmation and optional follow-up fields. Common elements you can add include:

  • Format: Header and paragraph elements thanking the respondent.

Page Logic and Control Visibility

Page logic is used to jump to specific pages depending on the answers given in the current page. Control visibility is used to shows questions on the same page based on the answer to a previous question. Page logic is accessed by clicking the 3 dots next to the page title and clicking edit, from here you can "Add Rule" in the page logic section. For control visibility you need to hover over a question and click the cog, you will see the control visibility options along the bottom. Note you cant used control visibility on the start or end pages

Step 3: Install Your Form

Unlike Feedback Buttons and Trigger-Based Forms, Embedded Forms require a specialized two-step implementation to ensure the inline layout renders perfectly inside your design wrappers.

1. Copy the Script Snippet

Click the first View code control to open the Script snippet modal overlay container. Copy this global snippet block and paste it directly into your website's main master page source code template, positioning it cleanly inside the <body> section right before your closing </body> tag so it loads flawlessly across your domain environments.

2. Copy the Widget Code (Placement Div)

Next, click the second View code control to reveal your tokenized Widget code string. This outputs a specific structural snippet block (e.g., <div ub-in-page="..."></div>).

  • Placement Rule: Copy this custom code wrapper and paste it directly into your page layout HTML at the exact geometric coordinate position (for example, pinned inside an accordion component or nested cleanly between two custom text blocks) where the functional question grid should physically appear inline to your end users.

Tip: You can also deploy and manage your core global background loading scripts via Google Tag Manager, please see our dedicated Google Tag Manager installation guide here!

Pro-Tip: Preview Your Design

Before finishing, click the Preview button at the top of the builder. This allows you to test the interactive flow—such as clicking the "Toggle" buttons—to ensure your follow-up questions appear exactly as intended within the embedded container.

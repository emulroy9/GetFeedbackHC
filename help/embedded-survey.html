Setting Up an Embedded Form

An Embedded Form lets you collect feedback directly within your website content (for example, at the end of help articles or documentation pages). Unlike the Feedback Button or Trigger-based Forms, an Embedded Form is placed directly into your page HTML and renders inline with your content.

Step 1: Start Your Form

  1. From the dashboard, navigate to Embedded Form and click Create (top-right). This opens the Build form view.
  2. Note the Add questions menu on the left — it lists all the question types available in the builder. Use this menu to drag or add controls to any page.
  3. You can also toggleStore IP Address and Store User Location from the Advanced Settings menu.

Step 2: Build the Experience

The builder uses a multi-page structure, allowing you to create a conversation with your users. Once you open the Build form view, you can add your chosen questions from the previously mentioned menu on the left.

Use the page tabs at the top of the builder to configure the Start page, any intermediary pages, and the End page. You can preview the form using the Preview button, and when you click Next you'll be shown the Install page where you can copy the global script and widget code.

The Start Page

This is the form your users see first. Customize the Title (e.g., "Was this useful for you?") and define the initial interaction.

  • Single question only: The Start page accepts only one control. Choose one starting interaction: Mood, NPS, or Toggle.
  • Mood: A quick emoji-based sentiment control for fast reactions.
  • NPS: The Net Promoter Score control for promoter/detractor measurement.
  • Toggle: A simple yes/no or helpful/not helpful choice that can trigger follow-ups.

Adding Pages

You can add follow-up questions to new pages that will appear after your start page.

These additional pages allow for a variety of question types, and multiple questions per page.

You can give these pages their own titles, and add any of the following question types from the Add questions menu:

  • Feedback: NPS, Rating, Mood
  • Input: Input text, Text area, Email
  • Choice: Dropdown, Checkbox, Radio buttons, Toggle
  • Format: Header, Paragraph

The End Page

Configure the final screen users see after submitting their feedback. Customize the Header (e.g., "Thank You") and the confirmation message.

Common End page elements

The End page typically contains confirmation and optional follow-up fields. Common elements you can add include:

  • Format: Header and paragraph elements thanking the respondent.

Step 3: Install Your Form

Page Logic and Control Visibility

Page logic lets you jump users to specific pages depending on answers in the current page. Control visibility lets you show or hide questions on the same page based on a previous answer.

To edit page logic, click the three dots next to the page tab and choose Edit. In the Page Settings dialog use Add Rule to create page-level jumps. To configure control visibility, hover over a question, click the cog (settings) and use the Control visibility options along the bottom of the question settings. Note: control visibility cannot be used on the Start or End pages.

Unlike Feedback Buttons and Trigger-Based Forms, Embedded Forms require a two-step installation to ensure the form appears in the correct location.

1. The Global Script Snippet

Click View Code for the Script Snippet. Copy and paste this code into your website's HTML, specifically just before the closing </body> tag on every page where you want forms to function.

2. The Form Placement Code

This specific "nonce" or identifier tells the global script exactly where to render the form on a specific page.

  • Placement: Copy the Form Code and paste it into the specific <div> or section of your HTML where the form should be displayed.

Pro-Tip: Preview Your Design

Before finishing, click the Preview button at the top of the builder. This allows you to test the interactive flow—such as clicking the "Toggle" buttons—to ensure your follow-up questions appear exactly as intended within the embedded container.

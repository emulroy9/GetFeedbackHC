Deploying GetFeedback via Google Tag Manager (GTM)

If your marketing or analytics teams use Google Tag Manager (GTM) to govern third-party script architectures, you can deploy the core GetFeedback script container across your entire domain in just a few clicks without manual engineering cycles.

Step-by-Step GTM Container Deployment

Before beginning, log into your platform dashboard, access the Install tab of your active project, and copy your unique JavaScript snippet container. Then, follow these steps inside your GTM workspace:

Step 1: Create a New Tag

  1. Access your Google Tag Manager workspace dashboard and select your target tracking container.
  2. From the left navigation options or the main overview panel, click Add a new tag.
  3. Assign your tag a clear structural name (e.g., "GetFeedback - Main Script Container").

Step 2: Configure Tag Properties

  1. Click inside the central Tag Configuration block box to open the template selection slide-out menu.
  2. Scroll through the default configurations or use the search field to select Custom HTML.
  3. Paste the global script block snippet you copied from your GetFeedback builder directly into the HTML text area field.
  4. Crucial Setting: Ensure that the "Support document.write" check box underneath the code area remains unchecked to prevent runtime performance conflicts.

Step 3: Establish the Global Trigger Rule

  1. Click directly into the lower Triggering options card configuration area.
  2. Select the default All Pages (Page View) conditional firing trigger option. This ensures your active components (like passive feedback buttons or contextually targeted forms) can look for matching page criteria anywhere on your domain.

Step 4: Save, Review, and Publish

  1. Click the blue Save button in the top right-hand corner of your setup panel frame interface.
  2. Click Submit on your master workspace container timeline block.
  3. Provide an optional version name noting the tag addition, and click Publish to push the deployment configurations straight to live production traffic.

Verifying Your GTM Deployment

Once GTM has finished publishing your container tags, you can confirm that the container script is actively communicating with your domain:

  1. Load your live website page viewport and open your browser's developer console interface (typically by hitting F12 or right-clicking and choosing Inspect Element -> Console).
  2. Type the terminal test execution command usabilla_live and strike Enter.
  3. If the tag has triggered flawlessly through GTM, the system will instantly return an instantiated background object function code footprint on the grid line interface.
Next Step: Now that your global GTM snippet container is live, return to your preferred campaign guide to build out custom logic: choose either the Feedback Button Setup, Trigger-based Forms Guide, or Embedded Surveys Workflow.

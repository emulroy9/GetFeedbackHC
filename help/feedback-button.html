Setting Up a Feedback Button (passive form)

A Feedback Button is a floating tab (or "button") on your website that allows visitors to share feedback at any time. This guide walks you through the flow for building, customizing, and installing your Feedback Button.

Getting Started

  1. Log in to GetFeedback.
  2. From the Home dashboard, locate the Choose how you want to collect feedback section or select your chosen option from the panel on the left.
  3. Find the Feedback Button card and click Create.
  4. The next page is divided into 3 sections: Build Form, Setup, and Launch.

Step 1: Build Your Form

The "Build Form" section is divided into three main views: the Start Page, Form Page, and End Page.

The Start Page

This is the initial screen users see when they click the feedback button.

  • Visual Feedback: Choose between "Specific" (allows users to point to an element on your site), "Generic" (site-wide feedback), or both. You also have the option for "No visual feedback"
  • Text Customization: Edit the Title (e.g., "Give us your feedback") and Subtitle to set expectations for your users.
  • Feedback Options: Customize the labels for the "Specific" and "Generic" feedback cards.

Adding a Custom Action Option

In addition to standard feedback types, you can add a third "Custom" card to your Intro Screen. This is ideal for directing users to a specific URL or triggering a custom script (like opening a live chat or a help article).

  1. Enable the Custom Option
    On the Start Page tab, scroll to the bottom of the left-hand sidebar and toggle on Add Custom Option.
  2. Customize the Content
    Once enabled, a third card will appear in the preview. You can then define:
    • Custom Title: The bold heading for the card (e.g., "Contact Support").
    • Custom Text: A short description to guide the user (e.g., "Talk to our team in real-time").
  3. Define the "On Click" Action
    Use the On Click dropdown to decide what happens when a user selects this card:
    • Redirect to URL: Automatically send the user to a specific webpage.
    • Execute Script: Trigger a specific JavaScript function on your site.

The Form Page

This is where you collect the actual data.

  • Add Questions: Click elements from the left sidebar, including:
    • Format: Input text or Paragraph fields.
    • Feedback: NPS, Rating scales, or Mood (Note that this question is mandatory).
    • Input: Email or Comment fields.
    • Choice: Drop-downs, Radio buttons, or Tags.
  • Edit Questions: Click on a question in the preview to toggle the Required setting or delete it.

The End Page

Configure the "Thank You" message users see after submitting.

  • Message: Add a custom thank you note.
  • Buttons: Edit the primary button text (e.g., "Back to site"). You can also toggle on a Secondary button for additional calls to action, like "Cancel" or "Visit Help Center."

Step 2: Setup (Customizing the Button)

Once your form is built, click Next to customize the appearance of the button that will live on your site.

Option A: Color Customization

  • Position: Use the dropdown to place the button (e.g., Bottom Right, Bottom Left).
  • Button Colour: Select from your brand palette or preset colors.
  • Button Type: Choose between horizontal or vertical layouts for the text/icon.

Option B: Upload Image for Button

If you prefer a custom look:

  • Upload a .png, .jpeg, or .jpg
  • Recommended Dimensions: 130 x 40 pixels for desktop; 70 x 35 pixels for mobile.
  • Retina Support: Upload an image at 2x the size and select Downscale image by 50% to ensure it looks sharp on high-density displays.

Advanced Settings

In both the Build and Setup phases, you can toggle Advanced Settings at the bottom of the sidebar to:

  • Store IP Address: Record the user's IP with their response.
  • Store User Location: Capture geographical data based on the user's connection.

Step 3: Install

The final step is to bring your Feedback Button to life on your website.

Important: If your website uses a Content Security Policy (CSP), you’ll need to add a hash to your website’s script-src. To find this hash, go to Setup, find your Feedback Button, then select Options > Installation. Copy the hash below your button code and add it to your site.
  1. Get the Code: Click View Code or Copy Code to grab your unique snippet.
  2. Paste the Code: Paste this snippet right before the tag in your DOM or the "custom code" section of your CMS.
  3. Save and Publish: Once your site is updated, the button will appear automatically.
  4. Preview: You can use the Preview box on the Install page to see how the button will behave before you leave the builder.
Next steps: After installation, head to How to Analyse Your Results to learn how to view and filter your feedback data.

Setting Up a Feedback Button

A Feedback Button acts as a passive, always-on floating asset anchored to the side of your web page, enabling visitors to proactively submit localized insights or global site reviews at any point during their session layout journey.

Step 1: Start Your Form

  1. From your dashboard workspace, locate the sidebar panel or main overview and select Feedback button, then click Create (top-right) to launch the builder.
  2. Note the progressive stage navigation bar displayed along the left margin of your browser window — this walks you through sequential Build form, Setup, and Install procedures.
  3. You can also activate back-end data tracking fields like Store IP address and Store user location by managing the toggles located inside the Advanced Settings block at the bottom of the tool pane.

Step 2: Build the Experience

The builder uses a dedicated three-stage layout system consisting of sequential page tabs located at the top of your canvas grid workspace to outline the user feedback interface.

The Start Page (Intro Screen)

This configures the portal frame card users interact with immediately upon clicking the floating tab. You can customize the structural headings and format the entry selection types using the left sidebar property tools:

  • Visual Feedback Selector: Open the dropdown menu to declare structural behavior restrictions. Choose between Specific or generic, Always specific, Always generic, or No visual feedback. These parameters govern whether users can highlight a precise design sub-element or capture a global full-page snapshot.
  • Text Labels: Edit the default Title (e.g., "Give us your feedback") and descriptive Subtitle text cards.
  • Feedback Options Accordions: Click open individual setting drawers to customize text labels inside the interactive selection cards (e.g., renaming the specific feedback card action text).
  • Custom Option Toggle: Flip on the Custom Option toggle switch at the bottom of the panel to inject an additional contact link card into the portal interface. This can provide direct user access to an out-of-band communication vector such as a contact form or chat integration layout.

The Form Page

This serves as the secondary data capture layer presented after a user makes their initial selection on the Start page. Construct this view by dragging or clicking components inside the Add questions sidebar module:

  • Feedback: Drop responsive rating components onto your page card, choosing between NPS metrics, star Rating rows, or interactive Mood scales (e.g., an emoji array card containing a "How do you feel?" prompt).
  • Input: Embed plain Input text fields, larger multi-line Text area boxes, or designated Email blocks.
  • Choice: Manage structured multi-option fields using Drop down selectors, Radio buttons layout cells, or custom item Tag elements.
  • Format: Provide contextual line breaks or textual instructions anywhere on the frame grid using a Paragraph block.

The End Page

Configure the terminal response view presented to respondents immediately following submission validation. Use the property cards to shape the confirmation messaging layout:

  • Title & Message text: Customize the transactional validation message lines (e.g., displaying "Thank you for your feedback!").
  • Button Customization: Define the redirection navigation path by modifying the main Button Text card (e.g., setting the layout card link text to "Back to site").
  • Give More Feedback Switch: Toggle this control to display a secondary text link shortcut on the completion card grid. This allows users to restart the survey sequence instantly by using a custom Button Label text link.

Step 3: Setup and Customize the Button

Click Next to progress past the structural build environment into the Setup canvas workspace. This panel manages the styling properties of the button asset that floats on your active client templates:

  • Button Color: Apply your corporate identity styling properties by selecting one of the palette nodes (e.g., green, blue, purple, black, or orange swatch profiles).
  • Button Type: Select the screen layout anchoring architecture by picking between standard vertical alignment frames or horizontal orientation modules pinned to the screen margin.

Step 4: Install Your Button

Clicking the final phase control moves your workspace frame into the terminal Install tab view to complete the site deployment sequence.

1. Code Snippet Copy and Placement

Click the View code or Copy code controls to capture the underlying platform embedding script module. Paste this compiled markup string straight into your master application layout templates, placing it immediately preceding the terminal closing </body> tag on pages where tracking is required.

2. Content Security Policy (CSP) Configurations

If your web layout platform operates under tight server restrictions, click the Include CSP Hash link on the modal panel code frame to access your deployment properties. You must copy these specific hash properties directly into your page headers.

Pro-Tip: Live Preview Verification

Before closing out your production setup, use the interactive preview container displayed directly on the Install setup tab. Click the rendered floating tab component layout directly within the preview frame to step through your entire responsive visual selection grid and ensure your data capture cells function properly before finalizing deployment.
